## ⭐ Featured Project

### 🚀 ProGuin — disciplined productivity system
**ProGuin** is a structured execution system built for **consistency — not motivation**.

- Python CLI core (fast, minimal, local-first)
- Android app (Kotlin + Compose)
- Shared logic approach (Python + Kotlin integration using Chaquopy)
- Timers, scheduling, notifications, persistent storage
